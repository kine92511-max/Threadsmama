# アカウントコンセプト・KPI・投稿比率

## コンセプト

「頑張りすぎないママの、リアルな暮らしの工夫」を発信するアカウント。共感を軸に信頼関係を
築き、その延長線上で「本当に良いと思うもの」を紹介して楽天アフィリエイト収益につなげる。

## KPIツリー（目安）

月10万円の収益 ← 承認率・単価に応じた成約数 ← アフィリエイトリンククリック数
← 投稿の保存・プロフィール流入 ← フォロワー数・エンゲージメント率 ← 投稿の質と本数

## 投稿運用の基本方針

- 毎日1〜2投稿を目安に運用する。
- 有益・共感系投稿とアフィリエイト系投稿の比率は **4:1〜3:1** を目安にする
  （アフィリエイト投稿ばかりだと信頼を失いフォロワーが離れるため、価値提供を優先する）。
- アフィリエイト投稿は「役に立つ情報＋自然な商品紹介」を徹底し、売り込み感を避ける。
- 1投稿で紹介する商品は基本1つ、多くてもリスト型で2〜3個までとする。
