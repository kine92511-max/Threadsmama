# NG表現・法令リスクチェックリスト

`05-proofreading` が校正時に必ず確認するリスト。法令・規約に関わるため、誤りに気づいたら
誰でもすぐに修正してよい。`03-value-empathy-writer` / `04-affiliate-writer` も執筆時に
事前チェックとして参照すること。

## 1. ステルスマーケティング規制（景品表示法）関連

2023年10月施行のステマ規制により、事業者から金銭・商品提供等を受けて行う表示は、
広告であることが一般消費者に明確に分かるようにする必要がある。

- **必須表記**: アフィリエイト投稿には本文冒頭付近またはハッシュタグに以下のいずれかを明記する。
  - `#PR`
  - `#広告`
  - `#楽天ROOM` （楽天ROOM経由であることが明確に伝わる場合）
  - `#アフィリエイト`
- **NG例**: 広告表記を投稿の最後の方に他のハッシュタグに紛れさせて分かりにくくする、
  文字色・サイズを極端に小さくする等、表記はしているが実質わかりにくいケース。
- **OK例**: 本文の最初の方、または目立つ位置に明記する。

## 2. 景品表示法（優良誤認・有利誤認表示）関連

- NG: 効果・性能について根拠のない「絶対」「必ず」「日本一」等の断定的表現。
- NG: 実際より著しく安く見せる二重価格表示（元値を不当に吊り上げて割引率を大きく見せる等）。
- NG: 在庫や期間限定を偽って煽る表現（実際は在庫が十分あるのに「残りわずか」と表示する等）。

## 3. 薬機法関連（健康・美容・発達に関する表現）

- NG: 「治る」「治療」「効果がある（医学的に）」など、医薬品的な効能効果を暗示する表現。
- NG: 子どもの発達について「必ず賢くなる」「絶対に◯◯ができるようになる」等の断定表現。
- OK: 「私はこう感じた」という個人の感想・体験としての表現に留める
  （例: 「使ってみて楽になったと感じた」）。

## 4. プライバシー・個人情報関連

- NG: 子どもの顔が判別できる写真をそのまま投稿する（許可を得ている場合を除き、
  スタンプ処理や後ろ姿の使用を推奨）。
- NG: 通っている保育園・幼稚園名、自宅周辺が特定できる情報の投稿。

## 5. 炎上リスク表現

- NG: 特定の育児方針（母乳育児 vs ミルク育児、共働き vs 専業主婦等）の優劣をつける表現。
- NG: 他のブランド・商品・アカウントを名指しで批判・比較する表現。
- NG: 政治・宗教・ジェンダーに関する意見表明につながる表現。
- NG: 不安を過度に煽る表現（「これを知らないと損する」「やらないと子どもがかわいそう」等）。
