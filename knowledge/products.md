# 楽天商品データベース

アフィリエイト投稿で紹介した（または紹介候補の）商品を蓄積する。価格・キャンペーン情報は
鮮度が命なので、参照時に必ず更新日を確認し、古ければ `01-research` が最新化すること。

## 記入フォーマット

```
### 商品名
- カテゴリ: (例: 時短家電 / 収納 / 離乳食グッズ / おもちゃ 等)
- 価格帯: (例: 3,000〜4,000円)
- 楽天レビュー: 件数・評価 (更新日: YYYY-MM-DD時点)
- 訴求ポイント: (どんな悩みを解決するか)
- 紹介実績: 紹介した投稿数 / 平均クリック数 / 成約数 / 成果報酬額（06から反映）
- 備考: キャンペーン情報、季節性、再紹介の可否など
```
