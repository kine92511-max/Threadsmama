# テンプレート: 楽天ROOM投稿

楽天ROOM上でのコレクション・商品紹介文に使う型。Threads投稿より短く、商品そのものへの
導線としての役割が強い。`post-writer` はこの構成に沿って執筆する。

## 構成

1. **一言タイトル/フック**: どんな人におすすめかを一言で（例: 「◯◯で悩んでるママにおすすめ」）。
2. **商品名・特徴**: 簡潔に商品の特徴を2〜3点挙げる。
3. **使ってみた感想（任意）**: 一言添えると信頼感が増す。
4. **ハッシュタグ**: カテゴリタグ＋広告表記を明記する。

## 文字数目安

100〜200文字程度（楽天ROOMは短文が基本）

## 例（穴埋め用の骨格）

```
◯◯で悩んでるママにおすすめ。

【商品名】
・◯◯なところがポイント
・◯◯にも使える

実際に使ってみて◯◯だった。

#PR #◯◯ #楽天ROOM
```

## チェックポイント

- [ ] 商品名・カテゴリが明確か
- [ ] 広告表記(#PR等)が入っているか
- [ ] 価格・スペック情報が`knowledge/products/`の情報と一致しているか（fact-checkerが確認）
- [ ] Threads側の投稿と内容が矛盾していないか
