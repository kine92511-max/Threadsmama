# テンプレート: 共感・あるある系Threads投稿

有益・共感系投稿（アフィリエイトリンクを含まない）に使う型。`copywriter` はこの構成に沿って
本文を執筆する。

## 構成

1. **フック（1〜2行目）**: 読者が「自分のことだ」と感じてスクロールを止める一言。
   問いかけ調が効果的（例: 「〇〇なこと、ない?」「〇〇って私だけ?」）。
2. **共感パート**: 読者の悩み・あるあるを具体的に言語化する。固有のディテール
   （子どもの年齢、時間帯、具体的なシーン）を入れてリアリティを出す。
3. **展開パート**: 自分の体験・気づき・工夫を語る（説教にならないよう「私はこうした」に留める）。
4. **具体パート（任意）**: 再現性のある具体的な工夫・コツを1〜2個提示する。
5. **CTA**: 「保存」「リプライで共感を集める」を狙う一文で締める
   （例: 「わかる人いたら教えて」「後で見返せるように保存しておいてね」）。

## 文字数目安

300〜500文字（Threads上限500文字）

## 例（穴埋め用の骨格）

```
◯◯なこと、ない?

うちの子(◯歳)、最近◯◯で。
毎日◯◯するのが正直しんどいなって思ってた。

でも◯◯してみたら、ちょっと楽になった気がする。

具体的には
・◯◯
・◯◯

みんなはどうしてる?よかったら教えてね。
```

## チェックポイント

- [ ] フックが共感から始まっているか（商品紹介・宣伝から入っていないか）
- [ ] 具体的なディテールが最低1つ以上入っているか
- [ ] CTAが「保存」または「リプライ」のどちらかを明確に狙っているか
