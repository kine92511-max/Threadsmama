# テンプレート: 商品レビュー系Threads投稿

アフィリエイト系投稿（楽天商品を紹介する）に使う型。`copywriter` はこの構成に沿って
本文を執筆し、`knowledge/04_compliance.md` の広告表記ルールを必ず守る。

## 構成

1. **フック（1〜2行目）**: 商品名からではなく、読者の悩みから入る
   （例: 「◯◯で困ってたんだけど、これに変えたら楽になった」）。
2. **共感・課題提起パート**: その商品を使う前の悩み・困りごとを具体的に描写する。
3. **商品紹介パート**: 商品名・特徴を、体験ベース（「これのおかげで〜が変わった」）で紹介する。
   スペックの羅列だけにしない。
4. **具体パート**: 価格帯・使ってみた感想・向いている人を簡潔に添える
   （価格・レビュー情報は `knowledge/products/` の該当ファイルを根拠にする）。
5. **広告表記**: 本文冒頭付近または末尾に `#PR` 等を明記する（詳細は `knowledge/04_compliance.md`）。
6. **CTA**: 「プロフィールのリンクから見てね」「楽天ROOMに載せてます」など、リンク誘導の一文。

## 文字数目安

300〜500文字（Threads上限500文字）

## 例（穴埋め用の骨格）

```
#PR

◯◯で毎日困ってたんだけど、
これに変えてから本当に楽になった。

【商品名】

◯◯なところが良くて、
特に◯◯な人にはおすすめしたい。

気になる人はプロフィールのリンクから見てみてね。
```

## チェックポイント

- [ ] 広告表記(#PR等)が入っているか
- [ ] 冒頭が商品紹介ではなく共感・課題提起から始まっているか
- [ ] 効果を保証・断定する表現がないか(`knowledge/04_compliance.md`参照)
- [ ] 価格・スペック情報が`knowledge/products/`の情報と一致しているか（fact-checkerが確認）
